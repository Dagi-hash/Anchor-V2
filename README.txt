ANCHOR - five priorities, one day (all files flat, no folders)

1. Upload to the ROOT of a new GitHub repo: index.html, style.css, app.js,
   anchor.png, mark.png, icon.png, make_icons.py, package.json, capacitor.config.json
2. Create .github/workflows/build.yml (Add file > Create new file) and paste build.yml.
3. Actions tab > run "Build Anchor APK" > download the Anchor-APK artifact.

Tap a task to complete it. Hold a task to edit or delete it.
